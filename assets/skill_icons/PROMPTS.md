# Skill icon prompts

Paste the **style block** first, then one skill line. Attach one of the existing icons (Fire Knight / Ranger / Cleric) as a style reference if your tool allows it.

## Style block (use with every prompt)

> Square game ability icon for a dark-fantasy roguelite, painted digital art, one bold central subject filling the frame, strong silhouette readable at 64×64 pixels, dramatic rim lighting and glowing magical effects, dark vignette background, rich saturated colours, no text, no letters, no border, no UI frame, centred composition, 1024×1024.

Save each file as `class_slot.png` (e.g. `mage_1.png`). Slot 1 = E, 2 = F, 3 = Q, 4 = R (ultimate).
